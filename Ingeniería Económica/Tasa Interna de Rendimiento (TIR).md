# Criterio
Si TIR >= TMAR Aceptar el proyecto
Si TIR < TMAR Rechazar el proyecto

# Métodos
- Ensayo y Error
- Método gráfico
- Calculadora o Computadora
# Ejercicio
Se planea invertir $1,500,000 en la modernización de la maquinaria de una procesadora de alimentos y se estima que con ello se logren ganancias adicionales a partir del tercer año y hasta el año 10 por $450,000. Si se tiene una TMAR del 30% Anual. Calcule la Tasa Interna de Rendimiento que puede tener la empresa durante los diez años e indique si este proyecto es viable.
Aplique el método de ensayo y error y el método gráfico.
