# ¿Qué es la Minería de Datos?
Es un conjunto de técnicas y tecnologías que nos permiten obtener un modelo de conocimiento a partir de un gran volumen de datos.
Con el fin de descubrir:
- Patrones
- Relaciones
- Reglas
- Asociaciones

# Data Mining
Lo que en verdad hace el data mining es reunir las ventajas de varias áreas como la Estadística, la Inteligencia Artificial, la Computación Gráfica, las Bases de Datos y el Procesamiento Masivo, principalmente usando como materia las bases de datos.

# Funciones
El data mining posibilita, entre otros aspectos:
- Filtrar todo el ruido caótico y repetitivo en sus datos.
- Entender qué es relevante y luego hacer un buen uso de esa información para evaluar resultados probables
- Acelerar el ritmo de la toma de decisiones informadas.

# ¿Qué es?
El data mining es una tecnología compuesta por etapas que integra varias áreas y que no se debe confundir con un gran software.
Durante el desarrollo de un proyecto de este tipo se usan diferentes aplicaciones de software en cada etapa.

# ¿Que hace la Minería de Datos?
1. Analiza datos
2. Descubre problemas
3. Forma modelos computarizados
4. Predice el comportamiento del negocio

# Objetivo
El objetivo del data mining es revelar información comercial exhaustiva utilizando técnicas avanzadas de análisis y creación de modelos.
Mediante la minería de datos se pueden hacer consultas mucho más complejas de los datos utilizando métodos de consulta convencionales.

# Ejemplo
Supongamos una empresa de desarrollo de software. Un equipo de ingenieros puede desarrollar aplicaciones informáticas y por cada una de ellas se recopilan distintos datos relacionados con la métrica del software (por ejemplo Horas de trabajo / Líneas de código / Número de errores por cada 1000 líneas de código, etc.).

# ¿Para que serviría la Minería de Datos a la empresa de desarrollo de software?
1. Saber el número de errores
2. Analizar el tiempo necesario para correcciones
3. Hallar errores antes concluir el proyecto

# ¿Dónde se utiliza?
La minería de datos tiene muchos campos de aplicación pues puede ser útil en todas las facetas que generen datos:
- Comercio y banca
- Medicina y Farmacia
- Seguridad y detección de fraude
- Recuperación de información no numérica
- Astronomía

# Proceso de la Minería de Datos
1. Selección y preparación de datos: Se recolectan, limpian y organizan los datos
2. Creación del modelo: Se aplican algoritmos para encontrar patrones
3. Pruebas y análisis: Se evalúa si el modelo funciona correctamente
4. Utilización del modelo: Se usa para tomar decisiones o hacer predicciones

# Ventajas de la Minería de Datos
## Descubre información no esperada
**Idea principal**
En la minería de datos, aunque se definan objetivos claros, el análisis puede revelar resultados no previstos.
**Explicación**
La combinación de distintas técnicas puede generar hallazgos inesperados que aportan valor al proyecto.
**Ejemplo**
Una empresa analiza los datos de compra de sus clientes para saber qué productos se venden más.
Sin embargo, al aplicar minería de datos, descubre que los clientes que compran refrescos también compran papas fritas, aunque no era algo que estaban buscando.
**Resultado**
La empresa usa este hallazgo para colocar ambos productos juntos y aumentar sus ventas.

## Brinda información de confianza
**Definición**
La minería de datos brinda información de confianza porque analiza datos reales mediante técnicas que permiten obtener resultados precisos para la toma de decisiones.
**Ejemplo**
Un taller mecánico analiza su historial de servicios realizados.
Con esos datos confiables, identifica qué refacciones se usan más y cuándo.
**Resultado**
Puede comprar mejor su inventario y evitar faltantes o pérdidas.

## Mejoras y ajustes en los procesos empresariales
**Definición**
La minería de datos permite identificar áreas de mejora en los procesos empresariales, optimizando tiempos, costos y eficiencia mediante el análisis de datos.
**Ejemplos**
Una empresa analiza el rendimiento de sus máquinas.
Detecta fallas frecuentes antes de que ocurran.
**Resultado**
Implementa mantenimiento preventivo y redice costos y tiempos de inactividad.

## Ayuda a una mejor toma de decisiones
**Definición**
La minería de datos ayuda a la toma de decisiones al proporcionar información objetiva y basada en datos, reduciendo la invertidumbre.
**Ejemplo**
Una empresa analiza sus ventas mensuales. Detecta en qué meses vende más y que productos son más demandados.
**Resultado**
Toma decisiones estratégicas como aumentar producción o lanzar promociones en temporadas clave.

## Analiza grandes cantidades de datos
**Definición**
La minería de datos es capaz de analizar grandes cantidades de información en poco tiempo, permitiendo identificar patrones y generar conocimiento útil.
1. Volumen de datos
2. Velocidad de procesamiento
3. Cariedad de datos
4. Identificación de patrones
5. Generación de valor

## Predicciones
**Idea clave**
La minería de datos permite predecir comportamientos futuros a partir de patrones encontrados en datos históricos.
**Puntos clave**
- Reduce la incertidumbre en decisiones
- Apoya el desarrollo de modelos de aprendizaje automático

## Construcción rápida de modelos
**Idea clave**
La minería de datos permite crear modelos en poco tiempo mediante algoritmos automatizados que seleccionan la mejor solución.
**Puntos clave**
- Automatiza el proceso de modelado
- Prueba múltiples algoritmos rápidamente
- Reduce el tiempo de desarrollo
- Selecciona el modelo más eficiente
**Ejemplo breve**
Un analista utiliza una herramienta de minería de datos que prueba varios modelos y en minutos obtiene el más preciso.

## Entrega resultados fáciles de entender
**Definición**
La minería de datos presenta los resultados de forma clara y comprensible, facilitando que cualquier persona pueda interpretarlos y tomar decisiones.
**Ideas clave**
- Representa datos mediante gráficas y visualizaciones
- Simplifica información compleja
- Facilita la interpretación para usuarios no expertos
- Apoya la comunicación de resultados
- Mejora la toma de decisiones

## Mejora la atención al cliente
Una empresa con el uso de la minería de datos puede conocer qué productos o servicios ofrecer a cada cliente acorde a sus necesidades, teniendo en cuenta diversos factores: el precio y el posicionamiento del producto, el contexto económico actual, la intensidad de la competencia , los datos demográficos, etc. Además reduce el riesgo de perder clientes.
Gracias a esto, la empresa puede proponer una oferta de productos o servicios adecuada para cada tipo de cliente, pero también establecer acciones promocionales específicas para aumentar sus ventas.

# Desventajas de la Minería de Datos

## Herramientas complejas
Las herramientas empleadas para la minería de datos son complejas y requieren de un manejo profesional. Es decir, se requiere capacitación y, en ocasiones, certificaciones específicas.
Esto hace que los profesionales en el ámbito sean escasos y altamente demandados, lo que puede resultar muy costoso para las organizaciones, especialmente para aquellas con recursos limitados o incluso escasos.

## No es infalible
La minería de datos no siempre proporciona información totalmente precisa. Todo esto se deberá en cierta parte a los objetivos puestos en la creación del modelo o en el propio proceso de la información.
Esta información depente de la calidad de los datos procesados. Los datos sesgados o incompletos pueden llevar a decisiones erróneas y ocasionar pérdidas financieras.

## Privacidad
Uno de los principales inconvenientes al tratar con información es el tratamiento de datos personales. Existe la preocupación por parte de las personas con las empresas, ya que estas pueden compartir entre otras empresas sus datos privados.
Esto implica la obtención y el análisis de grandes cantidades de información, personal controvertida y suelen preocuparse de que sus datos, como sus perfiles financieros o sociales , puedan ser utilizados o compartidos sin autorización.

## Costes
El coste de herramientas es menor comparado con precios de años atrás, sin embargo, el coste en tiempo, personal y consultoría se ha incrementado. Por eso se debe realizar un buen estudio donde se obtenga si el coste de la realización de la minería de datos será coherente con el beneficio esperado.

## Riesgos de seguridad
Existen numerosas amenazas relacionadas con el almacenamiento de grandes volúmenes de datos, que son susceptibles de sufrir filtraciones y ciberataques.
Si no se protege adecuadamente, información confidencial como números de la Seguridad Social o datos financieros puede ser fácilmente accedida por personas no autorizadas y, en consecuencia, utilizada indebidamente.

## Problemas de complejidad y escalabilidad
La mayoría de las técnicas de minería de datos funcionan bien con grandes conjuntos de datos, pero pueden no estar fácilmente disponibles en organizaciones pequeñas. Además, a medida que los conjuntos de datos se vuelven más extensos y se componen de estructuras anidadas, su manejo se vuelve mucho más complejo.

## Otras Desventajas
- El pre-procesamiento de datos puede ser tardado
- No siembre dará un modelo válido
- Si no se establecen objetivos de búsqueda concretos se obtendrán patrones equívocos o no interesantes

# Técnicas de la Minería de Datos
Los patrones que se pueden encontrar con la minería de datos dependen del conjunto de datos a analizar y del tipo de patrones que se quiera encontrar.
Las técnicas de minería de datos pueden ser **descriptivas** o **predictivas**
## Descriptivas
Caracterizan las propiedades generales de los datos en una base de datos
- Descripción de clases
- Análisis de asociación
- Clusters
## Predictiva
Realiza inferencias en los datos para poder realizar predicciones
- Clasificación y predicción
- Árboles de decisión
- Redes neuronales
- Regresión
- Agrupación

# Descripción de clases
Los datos almacenados se utilizan para localizar datos en grupos predeterminados
Por ejemplo: Una cadena de restaurantes podría minar datos de compra del cliente para determinar cuando los clientes los visitan y lo que normalmente ordenan. Esta información podría utilizarse para aumentar el tráfico al tener especiales del día.

# Análisis de asociación
Los datos pueden ser minados para identificar asociaciones.
- Conjunto de elementos
- Reglas para predecir la presencia de un elemento en la base de datos
- Manifestación de un elemento específico
- Elementos de los datos que con frecuencia aparecen conjuntamente
Ejemplo: Predicción de la manifestación de los gustos de las compras de los clientes

# Clasificación y predicción
Son dos tipos de análisis de datos, aquellos que pueden ser:
- Usados para clasificar datos: Predice clases de etiquetas
- Los que se usan para predecir tendencias: Predice funciones de valores continuos
Aplicaciones típicas incluyen análisis de riesgo para préstamos y predicciones de crecimiento.

# Agrupación
Agrupa los conjuntos de datos dentro de un clúster que contiene características similares
- Busca en los datos de entrada las características que aparecen juntas con frecuencia
- Los miembros de cada agrupación tienen propiedades similares
- Se agrupan de acuerdo a un criterio
- Útil para la identificación de anomalías en los datos y la creación de predicciones, para futuros comportamientos

# Redes neuronales
Son modelos predictivos no lineales que aprenden a través del entrenamiento.
Las tareas básicas de las redes neuronales son reconocer, clasificar, agrupar, asociar, almacenar patrones, aproximación de funciones, sistemas (predicción, control, entre otros).

# Árbol de decisión
Es un método analítico que a través de una representación esquemática de las alternativas disponibles facilita la toma de mejores decisiones, especialmente cuándo existen riesgos, costos, beneficios y múltiples opciones. También sirve para trazar un algoritmo que anticipe matemáticamente la mejor opción.
En la minería de datos sirven para obtener de forma visual las reglas de decisión bajo las cuales operan los consumidores, a partir de datos históricos almacenados.

# Regresión Lineal
El análisis de Regresión es un subcampo de "machine learning supervisado". Su propósito es establecer un modelo para la relación entre un cierto número de características y una variable objetivo continua.

## Tipos de Regresión Lineal
- Simple: Solo maneja una variable independiente
- Múltiple: Maneja varias variables independientes

# Clustering
Desarrolla una acción fundamental que le permite a los algoritmos de aprendizaje automatizado entrenar y conocer de forma adecuada los datos con los que desarrollan sus actividades.

## Métodos de Clustering
- Con aprendizaje automático
- K-means

# CUBE y ROLLUP de SQL
## ROLLUP
Es una extensión de GROUP BY que genera agrupaciones jerárquicas y agrega subtotales y total general

## CUBE
A diferencia de ROLLUP, no sigue jerarquía, sino todas las combinaciones

## ¿Cuándo usar cada uno?
Usa ROLLUP cuando:
- Hay jerarquía
- Quieres reportes simples
Usa CUBE cuándo:
- Necesitas análisis completo
- Hay múltiples dimensiones
