# Tipos de datos
-  Datos estructurados
	  Son los que tradicionalmente se han usado en el tratamiento de datos..
- Datos no estructurados
	  Se trata de datos en su forma original, tal y como fueron recogidos
- Datos semiestructurados
	  Siguen una especie de estructura, pero esta no es lo suficientemente regular como para gestionarla como datos estructurados

# Estructura y Visualización de Datos
Big Data es una plataforma que permite visualizar la información a través de los análisis llevados acabo sobre los datos que disponemos. Con esta plataforma se intenta llegar a un público más concreto, y una utilidad más acotada como un cuadro de mando integran de una organización.
